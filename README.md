# Jack Lanchantin

Personal site hosted on GitHub Pages at [jacklanchantin.com](https://www.jacklanchantin.com/).

- `index.html` is the homepage.
- `home/publications/index.html` contains the publications page at its original path.
- `css/site.css` contains the shared styles.
- `documents/` contains existing PDFs and other files linked from publications.

The Pages deployment publishes from the root of the `master` branch. Changes to
these files go live after a push to that branch. The site is plain HTML and CSS;
no Google Sites runtime or build tools are required.
